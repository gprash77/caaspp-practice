## Approval Boundary

This matrix defines coverage, complexity, response families, and distinct stimulus concepts. It does not contain finished prompts, keys, passages, scripts, source text, or media. Full content authoring must not begin until this matrix is approved or revised.

The matrix retains the longer Test 1 structure (69 items / 81 points) as a product decision. It uses the official adjusted blueprints for claim, target, and DOK constraints: [Mathematics adjusted blueprint](https://portal.smarterbalanced.org/library/en/mathematics-adjusted-blueprint.pdf) and [ELA/Literacy adjusted blueprint](https://portal.smarterbalanced.org/library/en/elaliteracy-adjusted-blueprint.pdf).

## Form-Level Easy Profile

- Familiar school, home, nature, neighborhood, and community contexts.
- Short sentences and direct task verbs.
- Visible labels, complete tables/diagrams, and progressive scaffolding.
- One principal reasoning demand at a time except where higher DOK requires integration.
- Plausible misconception-based distractors without tricks.
- Required DOK 3/4 coverage remains present but uses accessible language and supplied evidence.

## Runtime and Scoring Contract

- Every multi-select item authors `selection.min` and `selection.max`; every grid authors per-row minimum/maximum and, where needed, total minimum/maximum. The UI prevents excess choices and does not treat an under-selected response as complete.
- `numeric equivalent` uses parsed whole numbers, decimals, fractions, mixed numbers, and supported vulgar-fraction characters. Item-specific accepted numeric values and tolerance are serialized with the bank; no broad string guessing is used.
- Grid answers use stable `rowIndex:columnIndex` IDs. Ordered multipart fields preserve field order; unordered sets explicitly declare that scoring family.
- Line plots serialize bottom-up marks only, preventing holes. Scoring compares the authored count at every labeled value.
- Declarative constraints may combine field ranges, integrality, exact values, and reusable linear comparisons. Each constrained or partial-credit item receives positive, boundary, incomplete, and invalid test cases.
- Planned manual rubric IDs are immutable versioned identifiers. Their full criteria, scorer metadata, comments/date behavior, NS handling, and 0-versus-unscored tests will be registered with Test 2 content after matrix approval.
